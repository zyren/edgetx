# CN font notices

`CN_BASIC.FNT` is generated from the pinned upstream bitmap-font releases
listed in `tools/cn_fonts/manifest.json`. The release font is 2,015,744 bytes
with SHA-256
`C7D01736D365736DB04AEFD1FC103DB0FC9BAAA84841C058B0CE23828F894A79`.

The generated strikes contain glyphs from these sources:

- Fusion Pixel Font 10px and 12px, copyright TakWolf, SIL Open Font License
  1.1. See `licenses/fusion-pixel-font-OFL.txt`.
- WenQuanYi Bitmap Song 0.7.0-4 (9pt medium and 12pt bold), copyright the
  WenQuanYi Project contributors, GPL v2 with the font embedding exception.
  See `licenses/wqy-bitmapfont-GPL.txt` and
  `licenses/wqy-bitmapfont-README`.
- WenQuanYi Bitmap Song 1.0.0-RC1 (12pt medium), copyright the WenQuanYi
  Project contributors, GPL v2 or later with the font embedding exception.
  See `licenses/wqy-bitmapsong-COPYING` and
  `licenses/wqy-bitmapsong-README`.
- GNU Unifont 17.0.04. Its BDF copyright and license metadata is reproduced in
  `licenses/unifont-17.0.04-COPYRIGHT.txt`.

The license files above are copied byte-for-byte from the pinned source
archives, except the Unifont notice, which is the `COPYRIGHT` metadata line
extracted verbatim from `unifont-17.0.04.bdf.gz`.
